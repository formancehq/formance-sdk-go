# MirrorRewriteRule

Transforms a mirror log entry during v2→v3 translation. Exactly one scope field (createdTransaction, revertedTransaction, savedMetadata, deletedMetadata, or anyVariant) must be set. That scope determines both the CEL type of `log` in the rule's `match` and the set of actions the rule may carry. When `stop` is true and the rule matches (scope + predicate), no further rules are evaluated. Rewriting is a deterministic, translation-time projection; the source v2 ledger is never modified.
